### 🔎 Axiomrow: AI-Assisted Data Analysis

A Streamlit application where **every number shown is computed from the user's data, not generated by the language model.**

**Upload CSV → Data-quality gate → Analysis → Chat with data → Forecasts → PDF/Markdown report**

- Deterministic query engine answers exact questions first; the LLM is used only when needed
- LLM answers must return Python and SQL that are executed and cross-checked before any summary is shown
- Sandboxed code execution, read-only DuckDB, PII masking and rate limiting
- pytest suite and GitHub Actions CI (`pip-audit`, `bandit`, tests)

**Stack:** Python • Streamlit • pandas • DuckDB • Plotly • Groq / OpenAI APIs

[View project →](https://github.com/pranjali-sonkamble/Axiomrow) • [Live demo →](https://axiomrow.streamlit.app/)
